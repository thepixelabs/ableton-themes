Installing a theme

By hand — macOS
The folder is inside the app. Quit Live, open Applications in Finder, right-click your Ableton Live app, choose Show Package Contents, then open Contents/App-Resources/Themes and drop the .ask in.

By hand — Windows
C:\ProgramData\Ableton\Live 12\Resources\Themes\
If that isn't there, look for Resources\Themes inside your Ableton Live install folder.

Or run the installer script
It finds your Ableton install itself, copies every .ask file sitting in the same folder as the script, and refuses to run while Live is open. It's plain text — open it and read it before running it.

macOS — install-macos.command
macOS quarantines scripts downloaded from a browser, so the first time you must right-click it and choose Open. Double-clicking will be blocked. If you have more than one version of Live installed it asks which one.

Windows — install-windows.bat
Double-click it. If SmartScreen warns you, choose More info → Run anyway. If files fail to copy, the Themes folder needs elevation — right-click the script and choose Run as administrator.

Either way, remember a Live update replaces the app and wipes custom themes. Keep your .ask files somewhere safe and install them again afterwards.
